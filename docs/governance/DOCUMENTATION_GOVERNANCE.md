# Documentation Governance

Cada documento canónico tiene owner, estado y límites. El código/runtime/pruebas prevalecen sobre docs. Los documentos de archivo conservan historia, pero no son autoridad actual. No se copian secretos, settings locales, logs sensibles ni dumps.

Cambios transversales requieren registry y ledger. Una decisión durable requiere ADR; una hipótesis requiere `NOT_VERIFIED`/`PRODUCT_DECISION_PENDING`.
