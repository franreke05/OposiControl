# Change Protocol

1. Capturar estado Git y clasificar dirty work.
2. Leer fuentes canónicas y localizar owner Hashira.
3. Declarar alcance, evidencia, riesgos y reviewers.
4. Editar la mínima superficie autorizada.
5. Ejecutar pruebas/diff checks proporcionales.
6. Actualizar `CURRENT_STATE`, registry, ADR/contract si aplica y ledger.
7. Verificar no staging, no secretos y no cambios fuera de alcance.

En DB, publicación, auth real, despliegue y destructive operations se requiere human gate.
