# Roadmap

1. **Baseline y truth** — estabilizar evidencia de build/runtime, separar current/target y resolver contradicciones.
2. **Contracts and gates** — cerrar formato PDF con Arturo, modelo de roles y contrato OposiBot; aprobar ADRs necesarias.
3. **Remediation design** — diseñar auth, importación staged y migraciones canónicas con revisión cruzada.
4. **Implementation** — ejecutar cambios por dominio, con tests y gates humanos.
5. **Release and operations** — verificar runtime, despliegue, observabilidad y publicación.

Este roadmap no autoriza implementación en sí mismo. Las fechas, estimaciones y features concretas requieren decisión posterior.
